# Rigel

A reddit liked post system based on Ruby on Rails.

## Related Repos

- mcp tools that can CRUD posts to Rigel system. [rigel-sender](https://github.com/desonglll/rigel-sender)

## Features

- Authentication system using devise.
- Rich Text using Lexxy.
- CRUD posts.
- Reactions: like or dislike reactions.
- CICD: Docker compose and github workflow supports.
